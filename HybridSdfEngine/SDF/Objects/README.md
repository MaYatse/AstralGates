# Дополнительные примитивы

```csharp
using System.Numerics;
using HybridSdfEngine.SDF.Objects;

var cylinder = new SdfCylinder(new(-3, 1, 0), radius: 0.6f, height: 2f);
var torus = new SdfTorus(new(0, 1, 0), majorRadius: 0.8f, minorRadius: 0.25f);
var cone = new SdfCone(new(3, 1, 0), radius: 0.8f, height: 2f);
var triangle = new SdfTriangle(
    position: new(0, 1, 3),
    a: new(-1, -1, 0), b: new(0, 1, 0), c: new(1, -1, 0));
```

Все четыре объекта реализуют `ISdfObject`: их можно добавлять в `Scene`.
Доступны изменяемый `Material`, нормали, UV и касательный базис TBN.
Общий `SdfPrimitive` хранит позицию, поворот и материал. Цвет задаётся через
`DiffuseMaterial`, без отдельного свойства или параметра `Color` у примитива.
При `Material = null` используется белое диффузное покрытие.

## Размеры и расположение

| Примитив | Локальная геометрия | Пересечение лучом |
|---|---|---|
| `SdfCylinder` | Ось Y, радиус `Radius`, Y от `-Height/2` до `+Height/2`, оба основания закрыты | Аналитическое |
| `SdfCone` | Основание радиуса `Radius` при Y=`-Height/2`, вершина при Y=`+Height/2` | Аналитическое |
| `SdfTorus` | Кольцо вокруг Y; `MajorRadius` — радиус центральной окружности, `MinorRadius` — радиус трубки | SDF ray marching |
| `SdfTriangle` | Локальные вершины A, B, C относительно `Position`, нулевая толщина | Аналитическое, с обеих сторон |

`height` задаёт **полную высоту**. Размеры должны быть конечными и положительными.
У тора требуется `minorRadius < majorRadius`: поддерживается кольцевой торус
с открытым отверстием. Вершины треугольника должны быть конечными и не лежать
на одной прямой.

`Move(offset)` сдвигает объект, `Set(position)` задаёт положение его локального
начала. `Rotate(axis, angle)` вращает вокруг этого начала по мировой оси;
угол в радианах, ось автоматически нормализуется. У треугольника центр вращения —
`position`, вершины задаются в его локальной системе. Поворот тора на π/2 вокруг
X ставит кольцо вертикально:

```csharp
torus.Rotate(Vector3.UnitX, MathF.PI / 2f);
cylinder.Move(new(0, 0, 2));
```

Тела возвращают отрицательный `DistanceTo` внутри, положительный снаружи.
Треугольник возвращает **неотрицательное расстояние** до ограниченной поверхности:
у плоской фигуры нет внутреннего объёма. За пределами треугольника учитывается
ближайшее ребро или вершина, а не расстояние до бесконечной плоскости.

Нормаль треугольника определяется порядком A→B→C. Перестановка B и C меняет её
направление. Пересечение и тени работают с обеих сторон; диффузное освещение
использует заданную геометрическую нормаль, как у `SdfPlane`. У острых рёбер и
вершины конуса нормаль неоднозначна, поэтому выбирается конечное направление.

## Материалы и UV

```csharp
using HybridSdfEngine.Materials;
using HybridSdfEngine.Textures;

cone.Material = new DiffuseMaterial(ImageTexture.FromFile("Textures/albedo.png"));
triangle.Material = new DiffuseMaterial(new Vector3(0.8f, 0.2f, 0.1f));
```

На боковых поверхностях цилиндра и конуса U идёт вокруг Y, V от вершины/верхнего
основания вниз. Основания имеют плоскую проекцию в [0,1]. На торе U идёт вокруг
кольца, V вокруг трубки; обе координаты периодические. У треугольника вершины
A, B, C имеют UV (0,0), (1,0), (0,1). Координаты следуют за поворотом и переносом.
На швах и вершине конуса развёртка имеет обычные для таких фигур разрывы.

Торус участвует в существующей гибридной трассировке через свой SDF. Для него
важны `maxSteps` и SDF-допуск движка, особенно при касательных лучах; это обычно
дороже аналитических пересечений остальных трёх примитивов.

Проверки расстояний, пересечений, UV/TBN, случайных преобразований, материалов
и теней включены в обычный запуск:

```powershell
dotnet run --project HybridSdfEngine/Tests/ConsoleDisplayChecks.csproj -c Release
```
