# BRDF и BSDF

`IMaterial` читает текстуры и создаёт `MaterialSample` один раз на попадание.
`IBsdf` описывает отражение и прохождение света. `BsdfRenderer` получает свет,
проверяет видимость и продолжает путь по выбранным направлениям. Материалы и
BSDF не вызывают трассировку сцены.

## Материалы

```csharp
using System.Numerics;
using HybridSdfEngine.Materials;
using HybridSdfEngine.Textures;

var plastic = new PbrMaterial(new Vector3(0.8f, 0.15f, 0.05f))
{
    Roughness = new ConstantTexture<float>(0.3f)
};
var metal = new PbrMaterial(new Vector3(0.95f, 0.65f, 0.3f))
{
    Metallic = new ConstantTexture<float>(1f),
    Roughness = new ConstantTexture<float>(0.15f)
};
var glass = new DielectricMaterial
{
    TransmissionTint = new ConstantTexture<Vector3>(new(0.9f, 1f, 1f)),
    IndexOfRefraction = new ConstantTexture<float>(1.5f),
    Roughness = new ConstantTexture<float>(0f)
};
// sphere.Material = glass;
```

`PbrMaterial` объединяет диффузную составляющую с GGX-отражением: распределение
Trowbridge–Reitz, маскирование Smith и приближение Френеля Schlick. `Metallic`
меняется от 0 до 1, `Roughness` — от 0 до 1. При нулевой шероховатости зеркальная
часть становится дельта-распределением. При ненулевой шероховатости используется
небольшой нижний предел ширины GGX для численной устойчивости.

`DielectricMaterial` использует диэлектрические уравнения Френеля и закон
Снеллиуса. При нулевой шероховатости поверхность гладкая; при положительной
используется GGX для отражения и прохождения. При полном внутреннем отражении
остаётся отражённый путь. При одинаковых IOR свет проходит прямо. `TransmissionTint`
ослабляет прошедший свет на каждой границе, поэтому замкнутое тело окрашивает
его на входе и выходе. Для прозрачного бесцветного стекла задавайте белый tint.
Это поверхностное тонирование, без объёмного закона поглощения Бугера–Ламберта.

Оба материала имеют `Emission` и `NormalMap`; PBR имеет `Albedo`. Все цветовые
параметры и карты шероховатости/металличности, а также IOR стекла читаются через
`ITexture<T>`. Цвета и скаляры должны быть конечными, IOR — строго положительным.
Шероховатость и металличность ограничиваются [0,1].

```csharp
var packed = ImageTexture.FromFile("Textures/metallic-roughness.png",
    colorSpace: TextureColorSpace.Linear);
metal.Roughness = new ChannelTexture(packed, TextureChannel.Green);
metal.Metallic = new ChannelTexture(packed, TextureChannel.Blue);
```

## Рендерер

```csharp
using HybridSdfEngine.Render;

var renderer = new BsdfRenderer(scene)
{
    MaxBounces = 8,
    SampleCount = 32,
    BackgroundColor = new Vector3(0.05f, 0.08f, 0.12f)
};
Vector3 linearRgb = renderer.RenderRay(origin, direction);
```

`DiffuseRenderer` — совместимое имя того же рендерера. Прежние конструкторы,
`RenderRay` и настройки теней доступны. В основном приложении используется
`BsdfRenderer`; существующая сцена сохраняет свои материалы.

- `SampleCount` — число стохастических путей на один вызов `RenderRay`, по умолчанию 1.
- `MaxBounces` — число продолжений после первого попадания, по умолчанию 6, диапазон 0–32.
- `MaxDistance` и `MaxSteps` ограничивают поиск каждого попадания.
- `BackgroundColor` — постоянное окружение, по умолчанию чёрное.
- `OutsideIor` — IOR внешней среды, по умолчанию 1.
- `TraceDiffuseBounces` включает вторичные пути для чисто диффузных материалов,
  по умолчанию выключен. Составные PBR и стекло используют свою полную выборку BSDF.
- `Seed` задаёт воспроизводимый шум. При неизменных луче и Seed результат
  не зависит от порядка потоков. Накопление между кадрами не реализовано.

Каждый путь выбирает одно направление на каждой границе. Шум уменьшается
с числом выборок; SSAA4 дополнительно умножает число вызовов на четыре.
Ограничение глубины обрезает длинные пути и может затемнять многократные отражения.
Вычисления линейные/HDR; готовый `Shader` выполняет гамма-коррекцию, но tone mapping
пока отсутствует. Очень яркие блики могут обрезаться при выводе в 8-битный цвет.

Сами BRDF/BSDF нормированы, например Ламберт возвращает `Albedo / π`.
`DirectLightScale` по умолчанию равен π для сохранения прежней яркости источников;
значение 1 позволяет подавать взвешенную входящую радианс без этой компенсации.
Раннего выхода по чёрному альбедо нет: чёрный пластик всё ещё отражает блики.
Непрозрачные BSDF освещаются с лицевой стороны. У плоских объектов учитывайте
порядок вершин/направление нормали; пересечение с обратной стороны само по себе
не означает отражение света сквозь поверхность.

## Контракт IBsdf

Все направления — единичные мировые векторы, направленные **от** поверхности.
`OutgoingDirection` указывает на наблюдателя/предыдущую вершину пути.
`BsdfContext` хранит внешнюю геометрическую нормаль и IOR обеих сред.
`BsdfContext.Create` удобно использовать для отдельной границы с известной
внешней средой; рендерер передаёт IOR из стека вложенных замкнутых тел.

- `Evaluate` возвращает значение f, без косинуса и без яркости источника.
- `Pdf` возвращает плотность по телесному углу.
- `Sample` принимает три числа из [0,1) и возвращает направление, f, PDF и
  признаки `BsdfLobes`. Неудачная выборка имеет PDF=0.
- Для идеальных зеркальных событий `Evaluate` и `Pdf` равны нулю; `Sample`
  возвращает дискретную вероятность и соответствующий вес. Флаг `Specular`
  отличает такие события от непрерывных.

Рендерер умножает пропускание пути на `f * abs(cos) / pdf`. Для преломления
учитывается изменение радианса `(etaIncident / etaTransmitted)^2`.
Отражённые и прошедшие направления проверяются по геометрической нормали,
а смещение лучей выполняется на нужную сторону границы. Это предотвращает
самопересечения и перескок через поверхность из-за normal map.

Для своей модели реализуйте `IBsdf` и верните её в `MaterialSample.Bsdf`.
Старый конструктор `MaterialSample(albedo, emission, shadingNormal)` выбирает
Ламберта автоматически. Если модель пропускает теневые лучи, материал должен
вернуть `MayTransmitShadows = true`, а BSDF — реализовать `ShadowTransmittance`.
Материалы, BSDF и сцена изменяются только между кадрами.

## Прозрачные тени и границы применимости

`TransparentShadowsEnabled` по умолчанию включён. Если пропускающих материалов
нет, используется прежняя быстрая проверка любого препятствия. При наличии
стекла теневой луч последовательно проходит границы, учитывая tint и Френеля.
`MaxShadowIntersections` ограничивает число границ, по умолчанию 32.
При исчерпании шагов или границ свет консервативно блокируется.

Это приближение: теневой луч идёт прямо и не строит каустики. Его IOR/Френель
для сложных вложенных сред тоже приближённые. Основные отражённые/преломлённые
пути учитывают стек IOR для правильно вложенных замкнутых тел с внешними нормалями.
Произвольные пересекающиеся объёмы не моделируются как полноценная система сред.
Тонкое стекло отдельной моделью, объёмное рассеяние, дисперсия, спектральный рендер,
subsurface scattering и MIS для совпадающих геометрических/аналитических эмиттеров
не реализованы. Не задавайте один эмиттер одновременно геометрией и отдельным
источником, если не хотите учитывать их как два независимых источника.

Идеальные зеркальные пути видят геометрию и `BackgroundColor`. Отдельные `ILight`
не имеют видимой поверхности, поэтому для отражения изображения лампы нужна
геометрия с `Emission`; для бликов от обычных `ILight` задавайте ненулевую roughness.

## Проверки

```powershell
dotnet run --project HybridSdfEngine/Tests/ConsoleDisplayChecks.csproj -c Release
```

Проверяются нормировка Ламберта, взаимность и ограничение энергии GGX,
согласованность `Sample`/`Evaluate`/`Pdf`, обе ветви шероховатого стекла,
Френель, Снеллиус, полное внутреннее отражение, eta-поправка радианса,
отражённый эмиттер, замкнутое и вложенное стекло, цветные тени и отсутствие
выделений памяти на луч после прогрева.

Математические ориентиры: [BSDF representation](https://www.pbr-book.org/4ed/Reflection_Models/BSDF_Representation),
[dielectric BSDF](https://www.pbr-book.org/4ed/Reflection_Models/Dielectric_BSDF),
[microfacet theory](https://www.pbr-book.org/4ed/Reflection_Models/Roughness_Using_Microfacet_Theory).
