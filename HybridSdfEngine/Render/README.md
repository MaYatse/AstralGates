# Быстрый вывод в консоль

Публичные методы сохранены:

```csharp
var display = new ConsoleDisplay(); // Создать один раз, вне цикла кадров.
// В цикле:
display.ColoredGraphic(width, height, pixels);
display.Render();
```

RGB остаётся 24-битным. Цветной вывод использует `▀`: цвет символа задаёт верхний
пиксель, цвет фона — нижний. `width` и `height` задаются в пикселях изображения;
видимая область должна вмещать `width` столбцов и `(height + 1) / 2` строк.
При нечётной высоте нижняя половина последней строки заполняется чёрным.
Терминал должен поддерживать ANSI true color и отображение полублоков.
На Windows включается обработка VT-команд. При работе со стандартным интерактивным
выводом устанавливается UTF-8; исходная кодировка восстанавливается при освобождении.
`MaskGraphics` по-прежнему выводит
один символ на значение и использует `width` столбцов и `height` строк.

Консольное приложение использует ширину окна минус один столбец и удвоенную
высоту области изображения, оставляя две терминальные строки под служебный вывод.
F2 переключает SSAA по кругу: off → ×2 → ×4 → off. Начальный режим — off;
гамма-коррекция применяется во всех трёх режимах. Режим отображается в строке состояния.
F3 переключает внутреннее разрешение CPU-рендера: 100% → 75% → 50% → 100%
по каждой оси, начиная со 100%. Полная сетка вывода сохраняется при смене масштаба.
В строке состояния показаны процент, разрешение CPU и сетка вывода.

Для независимых разрешений используйте перегрузку:

```csharp
display.ColoredGraphic(renderWidth, renderHeight, pixels, outputWidth, outputHeight);
```

Она масштабирует изображение ближайшим соседом непосредственно в переиспользуемый
буфер вывода. Отдельный полноразмерный `Vector3[]` не создаётся. При одинаковых
размерах используется обычный проход без масштабирования. Обновление размера окна
пересчитывает внутреннее разрешение с сохранением выбранного процента.

F4 переключает Off ↔ Spatial, начиная с Off. Пространственный фильтр 5×5
обрабатывает вторичный свет в линейном цвете до гаммы и масштабирования.
Прямой свет и свечение первого попадания не фильтруются. Соседи отбираются
по объекту, глубине, нормали поверхности (с учётом normal map) и albedo.
При несовпадении поверхностей между SSAA-выборками пиксель не фильтруется.

Для использования вне консольного приложения передайте дополнительный callback:

```csharp
var shader = new Shader(width, height, pipeline.ShDr, pipeline.ShDrSample)
{
    SpatialDenoisingEnabled = true
};
var pixels = shader.RenderWithGamma(); // Также поддержаны SSAA2, SSAA4 и линейный SimpleRender.
```

`BsdfRenderer.RenderRaySample` возвращает обычный цвет, прямую составляющую и
`SurfaceGuide` первого попадания без повторной трассировки. Старый `RenderRay`
сохраняет контракт. Буферы фильтра создаются при первом включении, затем
переиспользуются; изменение разрешения сбрасывает их. При Off дополнительные
буферы не заполняются, callback с данными поверхности не вызывается.

Это базовое пространственное подавление шума без истории кадров. Оно добавляет
вычисления и память и может смягчать детали отражений/преломлений: глубина и
нормаль первого попадания не описывают видимые через поверхность объекты.
Режим не гарантирует отсутствие зерна и не заменяет дополнительные выборки
либо полноценную фильтрацию отражений. Прямые тени от сэмплируемых источников
относятся к прямому свету и этим проходом не подавляются.

Буферы переиспользуются. После прогрева и при постоянном разрешении цветной
рендерер не выделяет память на кадр. RGB-команды формируются напрямую в UTF-8;
повторяющиеся цвета символа и фона не требуют повторных RGB-команд. Кадр сравнивается с
последним успешно выведенным кадром. Неизменившиеся участки пропускаются,
неизменившийся кадр не вызывает запись. Изменение любой половины перерисовывает
целую ячейку с актуальными цветами обоих пикселей. Все изменения отправляются одной
записью в стандартный поток вывода. Позиционирование строк без перевода строки
предотвращает прокрутку на нижней строке.

После изменения размера окна, `Console.Clear()` или постороннего вывода вызовите
`display.Invalidate()` **перед** следующей подготовкой кадра. Изменение разрешения
и вывод через `MaskGraphics` автоматически вызывают полную перерисовку следующего
цветного кадра. Один экземпляр используется из одного потока; поток, переданный
в конструктор `ConsoleDisplay(Stream)`, остаётся собственностью вызывающего кода.

Проверки и воспроизводимый микробенчмарк без внешних пакетов:

```powershell
dotnet run --project Tests/HybridSdfEngine.Tests/ConsoleDisplayChecks.csproj -c Release
```

Проверки применяют ANSI-команды к модели экрана и сравнивают цвета после случайных
частичных обновлений, в том числе при изменении только нижней половины и нечётной высоте.
Бенчмарк сравнивает прежний вывод пробелами с полублоками для одного изображения
160×90 (занимаемая область терминала отличается), измеряет время и выделения памяти после прогрева. Используется
`Stream.Null`: результат характеризует подготовку и передачу буфера, а не FPS
реального терминала. Скорость отрисовки терминала и вычисления шейдера измеряются отдельно.
