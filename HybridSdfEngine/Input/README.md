# Ввод и камера

`SharpHookInputSource` использует SharpHook 8.0.1 для глобальных событий
клавиатуры и мыши. Подключается только интерактивным `ConsoleRenderer`:
экспорт GIF, бенчмарки и обычный `--smoke-test` не запускают перехват ввода.

## Управление приложением

```powershell
dotnet run --project AstralGates/AstralGates.csproj -c Release
```

Управление изначально выключено. Состояние отображается под изображением.

- **F1** включает или приостанавливает управление.
- **W / S** перемещают вперёд / назад по направлению взгляда.
- **A / D** перемещают влево / вправо относительно камеры.
- **Зажатая правая кнопка мыши** и движение мыши поворачивают камеру.
- **Esc** отключает управление.
- **Ctrl+C** завершает приложение и освобождает хук.

Это свободная камера: при наклоне вверх W также поднимает её. Скорость —
4 мировые единицы в секунду, чувствительность — 0.0025 радиана на единицу
смещения мыши. Их можно менять через `FlyCameraController.MoveSpeed` и
`MouseSensitivity`. Диагональное движение нормализовано. Наклон ограничен,
чтобы камера не переворачивалась. В интерактивном цикле шаг движения ограничен
0.1 секунды, чтобы длительная задержка кадра не вызывала скачок позиции.

SharpHook получает ввод глобально, включая другие приложения. **Перед
переключением в другое приложение нажмите Esc.** Автоматического определения
фокуса окна терминала нет. События не подавляются и продолжают приходить ОС.
Курсор не захватывается и не перемещается программно: при достижении края экрана
отпустите ПКМ, переставьте мышь и продолжите поворот. На системах, где SharpHook
выдаёт относительные события, они тоже учитываются.

## Использование в коде

```csharp
using HybridSdfEngine.Input;
using HybridSdfEngine.Render;
using SharpHook.Data;

var camera = new Camera { Position = new(0, 1, -10) };
var controller = new FlyCameraController(camera);
await using var input = new SharpHookInputSource();
await input.StartAsync(); // Возвращается после готовности хука.

// В начале каждого кадра, перед обновлением сцены и рендером:
InputFrame frame = input.State.ReadFrame();
controller.Update(frame, deltaTime);
bool held = frame.IsDown(KeyCode.VcW);
bool pressed = frame.WasPressed(KeyCode.VcW);
bool released = frame.WasReleased(KeyCode.VcW);
```

Одновременно запускайте только один глобальный хук во всём процессе.
`SharpHookInputSource` проверяет это для своих экземпляров. Не создавайте
отдельные хуки SharpHook параллельно с ним. `StartAsync` вызывается один раз;
`DisposeAsync` останавливает и дожидается завершения. `Completion` позволяет
заметить неожиданную остановку или ошибку хука.

`InputState` принимает события из другого потока под короткой блокировкой.
`ReadFrame` переносит данные в переиспользуемый `InputFrame`: он стабилен до
следующего `ReadFrame`. Вызывайте его один раз за кадр из потока обновления и
не сохраняйте снимок на последующие кадры. `WasPressed`, `WasReleased` и
`MouseDelta` сбрасываются после чтения; удержание сохраняется. Нажатие и
отпускание между кадрами дают оба перехода, поэтому короткий клик не теряется.
Повторы удерживаемой клавиши не дают повторного `WasPressed`.

Для другого источника ввода можно использовать `InputState.SetKey`,
`SetMouseButton`, `SetMousePosition` или `AddMouseDelta`. Абсолютная позиция
при первом событии задаёт базу без скачка. `Reset` освобождает удерживаемые
клавиши/кнопки и забывает базу мыши; его можно вызвать при потере фокуса.

Камера хранит позицию и базис направления, который пересчитывается при повороте.
В `RenderPipeline.ShDr` используются `Camera.Position` и
`Camera.GetRayDirection(uv)`. Начальное направление +Z сохраняет прежнюю
проекцию. Обновляйте камеру только между кадрами; обработчики ввода её не меняют.
Поворот использует смещение за кадр без умножения на `deltaTime`.

## Платформы и проверки

На macOS глобальному хуку требуется разрешение Accessibility. На Linux
возможности зависят от backend; Wayland имеет ограничения и требует повышенных
привилегий. Подробности: [SharpHook](https://github.com/TolikPylypchuk/SharpHook#supported-platforms).

Обычные проверки используют `SharpHook.Testing`, не отправляют события в ОС и
не устанавливают системный хук:

```powershell
dotnet run --project HybridSdfEngine/Tests/ConsoleDisplayChecks.csproj -c Release
```

Отдельная проверка запускает и останавливает настоящий системный хук без
инъекции клавиш и движений мыши:

```powershell
dotnet run --project HybridSdfEngine/Tests/ConsoleDisplayChecks.csproj -c Release -- --input-smoke-test
```
