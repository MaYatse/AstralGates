# Управление камерой в AstralGates

`FlyCameraController` — потребитель общего `HybridSdfEngine.Input.InputFrame`.
Назначения клавиш и правила активации относятся к демонстрационному приложению.
В движке [`Input`](../../HybridSdfEngine/Input/README.md) получает состояния
клавиатуры и мыши без назначений действий.

```powershell
dotnet run --project AstralGates/AstralGates.csproj -c Release
```

Управление изначально выключено. Состояние отображается под изображением.

- **F1** включает или приостанавливает управление.
- **W / S** перемещают вперёд / назад по направлению взгляда.
- **A / D** перемещают влево / вправо относительно камеры.
- **Зажатая ПКМ** и движение мыши поворачивают камеру.
- **Esc** отключает управление.
- **Ctrl+C** завершает приложение и освобождает хук.

Камера свободная: при наклоне вверх W также поднимает её. Скорость — 4 мировые
единицы в секунду, чувствительность — 0.0025 радиана на единицу смещения мыши.
Их можно менять через `MoveSpeed` и `MouseSensitivity`. Диагональное движение
нормализовано, наклон ограничен, поворот не умножается на `deltaTime`.
В интерактивном цикле шаг движения ограничен 0.1 секунды, чтобы длительная
задержка кадра не вызывала скачок позиции.

SharpHook получает ввод глобально. Перед переключением в другое приложение
нажмите Esc. Автоматического определения фокуса терминала нет. События не
подавляются. Курсор не захватывается: у края экрана отпустите ПКМ, переставьте
мышь и продолжите поворот. Относительные события тоже учитываются, если
платформа их предоставляет.

`ConsoleRenderer` читает один `InputFrame` и обновляет контроллер перед сценой
и параллельным рендером. Камера в `RenderPipeline` сохраняет начальную позицию
(0, 1, -10) и направление +Z. Экспорт GIF, бенчмарки и `--smoke-test` не
запускают источник ввода.

Проверки контроллера приложения:

```powershell
dotnet run --project AstralGates.Tests/AstralGates.Tests.csproj -c Release
```

Они проверяют движение, поворот и переключение управления через `InputState`
без системного хука и без отправки клавиш и движений мыши в ОС.
