# AstralGates Benchmarks

Бенчмарки BenchmarkDotNet для .NET 10. Запускать из корня репозитория в Release, без отладчика и одновременно работающего рендера.

## Запуск

```powershell
dotnet run --project AstralGates.Benchmarks -c Release -- --list flat
dotnet run --project AstralGates.Benchmarks -c Release -- --filter '*GammaBenchmarks*' '*RenderBenchmarks*'
dotnet run --project AstralGates.Benchmarks -c Release -- --gamma-accuracy
```

Можно выбрать другой набор через `--filter '*SdfBenchmarks*'` или `--filter '*LinqVsLoopBenchmark*'`.
Без аргументов BenchmarkSwitcher показывает выбор наборов.

## Сравнение гаммы

`GammaBenchmarks`: последовательная обработка готового линейного RGB-буфера 320×180 (57 600 пикселей). Измеряется весь буфер, а не отдельный канал. Подготовка данных и таблицы вынесена из измеряемого участка; выходной буфер переиспользуется.

- `Pow`: три MathF.Pow на пиксель, показатель 1 / 2.2.
- `LutLinear`: таблица из 4096 float (16 КиБ) на [0,1], линейная интерполяция.
- `LutDarkSafe`: та же таблица, но для 0 < x < 1/4095 используется Pow, чтобы уменьшить ошибку возле чёрного.
- Вне [0,1], включая отрицательные значения, NaN и бесконечности, обе таблицы используют Pow. HDR не обрезается.

Два набора входов: `Scene` — фиксированный кадр текущего RenderPipeline; `Gradient` — детерминированные перемешанные значения с равномерным, смещённым к тёмному и очень тёмным каналами. Результат зависит от распределения яркостей.

`--gamma-accuracy` сравнивает кандидатов с MathF.Pow на миллионе равномерных значений, логарифмической сетке возле нуля и обоих RGB-буферах. Выводятся максимальная и RMS-погрешность, разница после преобразования в 8 бит и число нечисловых результатов. Отдельно проверяется сохранение поведения для граничных, HDR и нечисловых входов. Преобразование в байт для этой проверки — усечение clamp(value * 255, 0, 255).

## Полный рендер

`RenderBenchmarks`: 160×90 и 640×360, фиксированное состояние текущей сцены.

- `GammaPow` — исходный Shader.RenderWithGamma, база сравнения.
- `NoGamma` — Shader.SimpleRender.
- `GammaLut` — экспериментальная замена гаммы на LutDarkSafe в таком же построчном Parallel.For; трассировка и коррекция объединены в одном проходе.
- `Ssaa2`, `Ssaa4` — исходные методы Shader, с Pow после усреднения.

Перед измерениями GammaLut сверяется с исходным рендерером; допустимая абсолютная погрешность канала — 0.001. Источники света и объекты не меняются между кадрами. Вывод в терминал, создание Shader, выделение буферов и обновление сцены не измеряются. Выделения внутренней инфраструктуры Parallel.For входят в результат.

Экспериментальная таблица находится только в проекте бенчмарков. Основной рендерер не изменён. Эти измерения оценивают CPU-рендеринг, а не FPS терминала.

Оба новых набора используют один запуск процесса, 5 итераций прогрева и 12 измерительных итераций. BenchmarkDotNet дополнительно калибрует число операций. Небольшая разница полного кадра может оказаться в пределах разброса — сравнивайте Error, StdDev и RatioSD.
